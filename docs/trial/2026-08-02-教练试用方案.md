# 教练试用方案（v3.2 之后第一步）

> 日期: 2026-08-02 | 目标: 用 1-2 家真实驾校验证「视频→方案→发布→留资」闭环

---

## 一、试用目标（一句话）

**验证"教练上传视频 → 得到 5 块《内容优化方案》→ 照着改、发出去 → 真的有学员私信留资"这条闭环成立，并收集真实反馈决定产品微调。**

不追求收费，追求"老板愿意继续用 + 出现真实留资"。

## 二、选 1-2 家的标准

| 条件 | 为什么 |
|------|--------|
| 老板/运营**有招生压力** | 有真实痛点才会认真配合 |
| 教练**已经在拍视频发抖音** | 有素材、会发布，闭环能跑通 |
| 愿意**配合记录数据**（截图播放量/私信） | 数据是验证闭环的证据 |
| 同城优先（如长沙） | 方案会注入城市关键词，本地化价值最大 |

> 备选：优先找你认识的、或学员多但线上弱的中小型驾校。

## 三、角色分工

| 角色 | 做什么 |
|------|--------|
| **你（运营/操作员）** | 跑工具出方案、微信跟进、记录数据、复盘 |
| **教练** | 提供素材视频 + 按方案改文案发布 + 反馈 |
| **老板** | 看结果，决定是否愿意继续用/付费（买单人） |

> 关键：**别替教练做内容**。让教练自己用工具出方案、自己发布——这样才能验证工具"他自己能不能用起来"。

## 四、试用流程（5 步）

### 第 0 步 联系铺垫
用话术 A 联系，确认意向 → 建一个微信小群（你 + 老板 + 教练）。

### 第 1 步 收集素材
让教练微信发 **2-3 条**最近拍的视频（已发过或没发过都行，5-15 分钟教学片，有说话内容即可）。视频里最好有教练口头教学——没有说话内容的纯开车视频会提示"没听到说话内容"。

### 第 2 步 生成方案（你操作）
跑工具出 5 块方案，把结果**整理成文字 + 图片**发到群里（教练/老板不会打开终端）：

```bash
py -3.12 run.py --web        # 网页上传，推荐
# 或 CLI：
py -3.12 run.py input/视频.mp4 --optimize --city 长沙
```

### 第 3 步 教练照着改/发
让教练按方案里的 **②脚本改写 / ③包装（标题·封面·简介）/ ④转化话术** 改后发布到抖音。
不要求一次全改，先改 **标题 + 简介 + 置顶评论**（最容易、效果最直接）。

### 第 4 步 跟踪留资
发布后 **第 3 天、第 7 天** 各记录一次（见第六节数据表）。有学员私信咨询就算"留资成功"。

### 第 5 步 复盘
两周后问老板三句话（见话术 D），收集真实反馈，记录到文档。

## 五、话术模板

### A. 初次联系（给老板/教练）
> 王校长好，我这边在做一个帮驾校"用现有视频招学员"的小工具，不让你多拍视频——就按你教练已经拍好的那些教学视频，AI 帮你改标题、改简介、改引导话术，让刷到的人愿意私信问你报名。想找 1-2 家驾校免费试用两周，教练和老板都不用花钱。你们最近有在发抖音招生吗？

### B. 演示介绍（第 2 步发方案时）
> 这是一条你们教练倒库的视频，工具自动出了 5 块建议：①哪里没拍好 ②开头怎么改才有钩子 ③标题/封面怎么起 ④置顶评论和私信话术 ⑤下一条拍什么。
> 你们不用全照做，先试 3 个最省事的：**换标题、改简介、加置顶评论**。发出去我帮你们盯数据。

### C. 第 3 天跟进
> 那条改过的视频数据怎么样？播放比之前高吗？有没有人私信问报名？把数据截图发我，我帮你们看哪里还能再改。

### D. 复盘（第 14 天，问老板）
> 1. 这两周用下来，你觉得这个东西对招生有没有帮助？
> 2. 哪里觉得不好用、或者没用？
> 3. 如果正式用，你觉得一个月愿意花多少钱？（只做意愿验证，不强求）

## 六、数据记录表（每条视频一行，反馈循环的落地点）

| 字段 | 说明 |
|------|------|
| 视频主题 | 倒库 / 侧方 / 科目三… |
| 工具诊断的问题 | 从方案①诊断里抄 |
| 建议的改写点 | 标题/简介/评论/话术 |
| 实际改了哪些 | 教练真正改了哪些 |
| 发布后 3 天 | 播放/赞/评/转 |
| 发布后 7 天 | 播放/赞/评/转 |
| **私信留资数** | 私信问"多少钱/报名/在哪练"的算留资 |
| 结论 | 哪条改得有效、哪条无效 |

> 建议放到 `work/trial_feedback.csv`（或任何表格），试用完统一复盘。

## 七、成功标准（做到什么算验证通过）

1. **每家至少发布 2-3 条** 改后的视频
2. **至少 1 条产生真实留资**（私信咨询报名）
3. **老板明确表示愿意继续用 / 有付费意愿**（口头上即可）
4. 收集到 **≥5 条**真实反馈（哪里好/哪里不好）

三条全达成 → 闭环成立，可以谈正式收费/进一步做产品。
做不到 2（没留资）→ 大概率问题出在"内容/发布/留资承接"，复盘后决定改哪。

## 八、注意点（避坑）

1. **别替教练做内容**——你做的话验证不了"他自己能用"。
2. **留资要定义清楚**——"私信问报名/价格/在哪练"才算；单纯点赞不算。
3. **单条播放受平台流量影响**——别只看单条，看趋势 + 教练愿不愿意继续用。
4. **视频数据要主动要**——教练多半不会主动给，第 3/7 天主动要截图。
5. 若教练没发过抖音 → 提示他"发出去才是闭环"，可以先从发一条改后的视频开始。
