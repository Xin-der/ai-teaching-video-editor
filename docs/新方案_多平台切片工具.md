# 多平台智能切片工具 · 方案设计

> 2026-07-28 | 替代旧"全自动出片"方案  
> 目标：长教学视频 → AI 理解内容 → 智能切片 → 多平台适配导出 + 文案生成

---

## 核心流程

```
你的一次操作:
  放视频 → 运行 → 确认分段 → 一键导出全平台

AI 在背后做的:
  input/video.mp4
      │
      ▼
  [Step 1] 音频提取 + ASR 语音转文字
      │
      ▼
  [Step 2] 场景检测（PySceneDetect 自动分镜）
      │
      ▼
  [Step 3] VLM 看关键帧 → 场景标签（location/activity/visible_elements）
      │
      ▼
  [Step 4] 智能分段：合并相邻同主题段 → 5-8 个有意义的片段
      │
      ▼
  [Step 5] 评分引擎：关键词匹配 + 时长占比 + 画面强调信号
      │
      ▼
  [Step 6] 你预览确认分段（简单的文本列表 or Web 界面）
      │
      ▼
  [Step 7] 并行导出:
    ├─ 抖音版 (9:16 + 大字幕 + 关键词弹窗 + BGM + 进度条)
    ├─ B站版 (16:9 + 标准字幕 + 知识卡片 + 章节)
    ├─ 小红书版 (1:1 + 要点覆盖 + 封面图)
    └─ 文案稿 (标题/简介/标签/评论区文案)
      │
      ▼
  output/{片段名}/
    ├── douyin.mp4
    ├── bilibili.mp4
    ├── xiaohongshu.mp4
    └── copy.md
```

## 评分引擎

### 评分维度

| 维度 | 权重 | 计算方式 |
|---|---|---|
| **关键词密度** | 30% | ASR transcript 中强调词（"记住"/"重点"/"千万别"/"考试"/"扣分"）出现频率 |
| **知识库匹配** | 25% | 片段主题匹配驾考高频扣分点 → 加权 |
| **时长占比** | 20% | 片段时长占总视频比例 > 15% → 高分（教练花时间讲的就是重点） |
| **画面强调信号** | 15% | VLM 检测到文字叠加/特写镜头/路线图 → 说明教练做了视觉强调 |
| **重复讲解** | 10% | 同一主题在视频中出现了 2 次以上 → 重要 |

### 评分输出

```json
{
  "segment_id": 2,
  "topic": "夜间灯光操作",
  "score": 0.82,
  "scores_detail": {
    "keywords": 0.28,

    "duration_ratio": 0.16,
    "visual_emphasis": 0.08,
    "repetition": 0.05
  },
  "recommendation": "强烈推荐",
  "platform_suitability": {
    "douyin": "高",
    "bilibili": "高",
    "xiaohongshu": "中"
  }
}
```

## 技术栈

| 层 | 技术 | 用途 |
|---|---|---|
| ASR | FunASR Paraformer | 中文语音转文字，本地运行 |
| VLM | qwen3.7-plus (DashScope) | 看关键帧，输出场景标签 |
| 场景检测 | PySceneDetect | 自动分镜 |
| 渲染 | MoviePy | 视频裁切+叠加+字幕+导出 |
| 文案 | qwen3.7-plus (OpenAI兼容) | 根据 transcript + 标签生成各平台文案 |
| 评分 | Python 规则引擎 | 确定性打分，不调 LLM |
| 模板 | JSON 配置文件 | 各平台样式参数 |

## 和旧方案的核心区别

| 维度 | 旧方案（已废弃） | 新方案 |
|---|---|---|
| **核心任务** | AI 学剪辑风格 → 全自动渲染 | AI 理解内容 → 切片+多平台导出 |
| **AI 难度** | 极高（模仿剪辑师审美） | 中等（理解教学内容） |
| **渲染目标** | 还原剪映工程的所有特效 | 模板化叠加（标题+字幕+进度条+卡片） |
| **分段方式** | 依赖工程文件 draft_content.json | PySceneDetect 自动 + AI 合并 |
| **用户参与** | 期望零参与 | 确认分段 + 可选调参数 |
| **输出数量** | 1 个 mp4 | N 个片段 × 3 个平台 = 3N 个 mp4 + 文案 |
| **失败后果** | 10 小时出错的 mp4 | 至少分段和文案是对的 |
