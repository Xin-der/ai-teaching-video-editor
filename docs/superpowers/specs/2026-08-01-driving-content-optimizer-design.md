# 驾校内容优化工具 · 设计文档

> 日期: 2026-08-01 | 状态: 已评审

---

## 一、背景与目标

### 为什么做这个（真实用户调研结论）

和驾校教练、驾校老板的真实对话得出三条结论：

1. **教练不缺内容**。他们自己拍练车视频，会发抖音，也有引导和私域。
2. **真正痛的是没人看、没转化**。视频没曝光，有曝光也留不住学员。
3. **教练不会用复杂工具**。目标人群年纪偏大，对剪辑/AI 软件陌生，不会主动学、不会主动用。

由此否定原方向（"长视频 → AI 切片 → 多平台导出"）：切片是假需求，渲染是打不赢剪映的仗。
新方向聚焦一句话：

> **把教练随手拍的素材，变成学员看了会私信的短视频。**

### 工具定义

> **上传一条视频（或粘贴文字），得到一份《内容优化方案》——照着改、照着发。**

工具不重新剪辑视频，它从**内容**里提炼方案。核心价值在"内容诊断 + 说服力改写 + 包装 + 转化话术 + 选题"，而不是视频渲染。

---

## 二、用户画像

**用户不是老教练，是"驾校里负责招生的人"（驾校老板 / 运营）。**

| 角色 | 定位 | 说明 |
|------|------|------|
| 教练 | 内容来源 | 素材视频是他拍的；他不使用工具 |
| 驾校老板/运营 | **工具用户 + 买单人** | 关心招生、有预算、更年轻、愿意为结果花钱 |

### 交互原则（对这类人群的硬性要求）

前台必须极简，零学习成本：

> **选视频 → 点生成 → 复制粘贴到抖音。没有第二步。**

诊断、改写、选题等思考全部藏在后台。用户只拿到"能直接发出去的东西"。如果用户需要"读一份报告"才算完，产品就失败了。

---

## 三、核心流程

```
输入（视频文件 或 粘贴文字，可选填城市）
   │
   ▼
① ASR 转录（视频里有说话内容时）
② 可选 VLM 看帧（≤4帧，非阻塞，失败不阻断）
   │
   ▼
③ LLM 生成《内容优化方案》（5 块）
   │
   ▼
输出（Web 页展示 + markdown 文件，全部可复制）
```

### 输入要求

| 输入形式 | 说明 |
|----------|------|
| 视频文件 | 原始素材、剪辑过、已发布成品**均可**，只要里面有教练的说话内容 |
| 粘贴文字 | 脚本/简介/口述，兜底入口，不挑形式 |
| 城市（可选） | 填了则 LLM 注入同城关键词、选题更本地化 |
| 平台（可选，默认抖音） | MVP 先只支持抖音，字段预留 |

**硬性前提：视频里必须有说话内容。** 纯开车静音没有可提炼的东西，此时引导用户粘贴文字。

---

## 四、输出：《内容优化方案》5 块

### 格式（JSON，LLM 返回后校验）

```json
{
  "diagnosis": {
    "summary": "这条为什么没人看（3句话以内）",
    "issues": ["开头没钩子", "没痛点", "没同城词", "没引导"],
    "strengths": ["教学点清晰"]
  },
  "script_rewrite": {
    "hook": "开头3秒文案",
    "body": "干货主体（保留教练原话，重组结构）",
    "proof": "证明/案例（学员通过、资质）",
    "cta": "引导话术（关注/私信/评论）"
  },
  "packaging": {
    "title": "带同城+关键词的标题（≤30字）",
    "cover_text": "封面文字",
    "description": "简介（100字内）"
  },
  "conversion": {
    "pinned_comment": "置顶评论文案",
    "profile_bio": "主页简介文案",
    "dm_opening": "私信开场白话术"
  },
  "next_topics": [
    { "title": "选题1", "why": "学员为什么在搜这个" }
  ]
}
```

### 示例（倒车入库教学）

- **diagnosis**：开头 15 秒在倒车没钩子；全片没有"学员容易挂科"的痛点；没城市词；没引导。教学视角，学员不搜。
- **script_rewrite.hook**：科目二挂科三次？十有八九是倒库点位没对。
- **packaging.title**：长沙科目二倒库三步法，教练亲测
- **conversion.pinned_comment**：想学的扣 1，私信我发点位图

## 五、技术架构

### 组件

```
engine/
  ├── advisor.py        ← 新增：核心编排（输入 → ASR → VLM → LLM → 方案）
  ├── pipeline.py       ← 复用：音频提取 + ASR + 场景/VLM 步骤（小改，暴露可复用方法）
  └── analyzer.py       ← 改造：新增 generate_optimization_plan() + prompt
knowledge/driving_exam.json         ← 复用：领域上下文（扣分点/痛点/文案模板）
web/
  ├── app.py            ← 改造：新增 /api/optimize 路由 + 结果页
  └── templates/        ← 新增 optimize 页面（上传/粘贴 → 方案 → 复制）
run.py                  ← 改造：新增 --optimize 模式（CLI 测试用）
```

### 数据流

1. `web/app.py` 接收 POST（文件 或 文字 + 可选城市/平台）→ 启动后台线程
2. `engine/advisor.py` 编排：
   - 有视频 → 复用 pipeline 的音频提取 + ASR 得到 transcript
   - 可选：抽 ≤4 帧做 VLM 摘要（非阻塞，失败跳过）
   - 无视频 → 直接用粘贴的文字
   - transcript 为空 → 返回明确错误"没听到说话内容"
3. 调用 `analyzer.generate_optimization_plan(transcript, vlm_summary, city, platform)`
4. 返回 5 块 JSON → 前端渲染 + 同时写 markdown 文件到 work/ 或 output/

### 复用与砍掉

| 模块 | 处置 |
|------|------|
| `engine/pipeline.py` ASR/VLM 步骤 | ✅ 复用（小改，暴露公开方法） |
| `engine/analyzer.py` | ✅ 改造，新增方案生成方法 |
| `knowledge/driving_exam.json` | ✅ 复用为领域上下文 |
| `web/app.py` + Flask | ✅ 复用 |
| `engine/exporter.py`（渲染/切片） | ⏸ 保留文件，MVP 调用链不涉及 |
| `engine/scorer.py` | ⏸ 保留文件，MVP 不调用 |
| `engine/style_manager.py` | ⏸ 保留文件，MVP 不调用 |
| `templates/*.json`（平台导出模板） | ⏸ MVP 不涉及 |

> 原则：MVP 只新增/改造必要路径，**不删除**任何旧模块（以后可能复用），只让它们退出调用链。

## 六、错误处理

| 场景 | 处理 |
|------|------|
| 视频里没有说话内容 | 明确提示 + 引导粘贴文字 |
| ASR 失败 | 提示失败，建议粘贴文字 |
| VLM 失败 | 非阻塞，跳过继续（不影响出方案） |
| 未配置 DASHSCOPE_API_KEY | 复用现有检查，报错提示配置 |
| LLM 返回非法 JSON | 重试一次，仍失败则报错 |
| 输入为空（无文件无文字） | 400 校验 |

## 七、测试

1. **单元测试（tests/）**
   - `generate_optimization_plan()`：给定固定 transcript，断言 5 块结构完整、字段非空
   - LLM 非法 JSON 时重试逻辑
2. **集成测试**
   - 用现有样本 `input/PNIK4383.MOV` 跑一遍 `run.py --optimize`，确认出方案
   - 用纯文字输入跑一遍，确认兜底路径
3. **人工验收**
   - Web 页：上传视频 → 生成 → 每块可一键复制

## 八、MVP 范围（明确不做）

- ❌ 账号系统 / 多用户 / 云端
- ❌ 数据看板 / 反馈循环（后续再议）
- ❌ 视频渲染 / 切片 / 特效
- ❌ 抖音链接抓取（合规风险）
- ❌ 多平台（B站/小红书），字段预留但不实现
- ❌ 批量处理

**MVP 就一句话：一条视频 → 一份方案，本地跑通。**

---

## 九、验证标准（做到什么算成功）

1. 一条真实的驾校视频进去，出来的 5 块方案**教练/老板看一眼就能用**（不用二次解释）
2. 从上传到出方案，**全程 < 5 分钟**（含 ASR）
3. 拿 1-2 家真实驾校试用，**老板愿意持续用、并愿意为此付费**（意愿验证，不要求立刻付费）
