## 第一段：学风格（一次性，已完成）

如果你已经跑过第一段，`style_labels.json` 已在项目根目录，**跳过此段**。

如果要重新学习新风格：

1. 放入参考视频到 `ref/`
2. 依次运行：
```powershell
python scripts/run_asr.py            # ASR 语音识别
python scripts/describe_frames.py    # VLM 描述画面

```
3. 审核 `style_labels.json` 和 `skill_style.md`

## 第二段：每次出片

### 准备素材

在 `input/` 下放入：

```
input/
├── video.mp4              ← 必填：要处理的新视频
├── route_map.png          ← 可选：路线图（蓝色路径）
├── foot_closeup.mp4/jpg   ← 可选：脚部操作特写
└── dashboard_closeup.mp4/jpg ← 可选：仪表盘特写
```

### 运行

```powershell
cd "D:\Projects\ai视频剪辑agent"
.\venv\Scripts\activate

# 完整管线
python run.py

# 或者指定视频
python run.py --input "D:\我的视频.mp4"

# 跳过 ASR（已有结果时加速）
python run.py --skip-asr

# 跳过 VLM（已有结果时加速）
python run.py --skip-vlm
```

### 等待时间

| 步骤 | 预估耗时 | 说明 |
|---|---|---|
| 音频提取 | ~30秒 | 16kHz mono |
| ASR 识别 | 2-5分钟 | FunASR 本地 |
| 场景检测 | 1-2分钟 | 自动分镜 |
| 抽关键帧 | ~1分钟 | 每段1张 |
| VLM 描述 | 10-30分钟 | 取决于分段数，每段~30秒 |
| 标签匹配 | <1秒 | 确定性引擎 |
| 渲染 | 5-15分钟 | 取决于视频长度和分辨率 |
| **总计** | **20-55分钟** | |

> 如果 VLM 结果已存在（`work/run_xxx/frame_descriptions.json`），加 `--skip-vlm` 可跳过最慢的步骤。

### 拿成品

去 `output/` 取 `成片.mp4`。

## 修改风格

编辑 `style_labels.json`：

| 想改什么 | 改哪里 |
|---|---|
| zoom 推进幅度 | `RULE_ZOOM.actions[0].params.scale_end`（默认 1.12） |
| 路线图大小/位置 | `overlay_route_map` 的 `position` 和 `scale` |
| 画中画大小 | `RULE_PIP` 里的 `scale: 0.25` |
| 字幕字号 | `burn_subtitles` 的 `font_size`（默认 28-32） |
| 红点大小 | `animate_red_dot` 的 `scale` 或直接改 `dot_size` |

## 常见问题

**Q: VLM 太慢怎么办？**
A: 加 `--skip-vlm` 跳过（如果有之前的结果）。或者减少分段数：`--max-segments 10`

**Q: 渲染内存不够？**
A: 加 `--resolution 720p` 降低输出分辨率

**Q: 红点位置不准？**
A: 在视频里多加文字标签（"前方路口右转"等），VLM 读到文字比纯靠画面匹配准得多

**Q: 想处理别的类型视频（非科三）？**
A: 直接用就行，VLM 会自动输出对应的 activity 标签。如果标签不在规则里，在 `style_labels.json` 的 `RULE_PIP.trigger.any_of` 里加上即可
