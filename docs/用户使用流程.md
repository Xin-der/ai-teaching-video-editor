> 版本 v1.0 | 2026-07-27  
> 适用：驾考教学视频（科三路考 / 科目二 / 日常练车），可按风格模板自动出片

## 你的工作流程（一句话版）

```
准备素材 → 放到 input/ → 运行 python run.py → 去 output/ 拿成品
```

---

## 详细步骤

### 第一步：准备素材（5 分钟）

在 `input/` 文件夹下放入以下文件：

```
input/
├── video.mp4              ← 必填：你要处理的视频
├── route_map.png          ← 可选：本期视频的路线图（有就放）
├── foot_closeup.mp4/jpg   ← 可选：脚部操作特写素材
└── dashboard_closeup.mp4/jpg ← 可选：仪表盘/灯光特写素材
```

**视频要求**：
- 格式：MP4 或 MOV
- 时长：3-15 分钟（推荐）
- 内容：驾考教学或练车相关视频

**路线图素材**：
- 带蓝色路径的路线图（系统自动扣蓝得到透明背景）
- 如果有文字标注更好，AI 可以读取文字判断位置

**特写素材**（可选）：
- 脚部踩离合/刹车/油门的特写画面
- 仪表盘和灯光拨杆的特写画面
- 如果没有，AI 跳过对应效果

---

### 第二步：运行命令（1 分钟）

打开 PowerShell，执行：

```powershell
cd "D:\Projects\ai视频剪辑agent"
.\venv\Scripts\activate

```

或者如果你只想跑某一步：

```powershell

```

### 第三步：拿成品（等待 3-10 分钟）

去 `output/` 文件夹取 `成片.mp4`。

## AI 在背后做了什么

```
你的视频
    │
    ▼
┌─────────────┐
│ 1. ASR 识别  │  FunASR 中文语音转文字
└──────┬──────┘
       ▼
┌─────────────┐
│ 2. VLM 分析  │  qwen3.7-plus 看画面 → 结构化标签
└──────┬──────┘  (判断：有文字？有语音？有路线图？)
       ▼
┌─────────────┐
│ 3. 标签匹配  │  确定性匹配引擎 → 生成编辑操作列表
└──────┬──────┘  (4条分支自动选择)
       ▼
┌─────────────┐
│ 4. 渲染输出  │  MoviePy 视频合成 → mp4
└─────────────┘
```

### 四条处理分支

| 分支 | 条件 | 效果 |
|---|---|---|
| **A** | 视频有文字标签 + 有路线图 | 红点精确跟随路线移动（最准） |
| **B** | 有语音讲解 + 有路线图，无文字 | ASR 关键词提取 → 红点粗略移动 |
| **C** | 纯驾驶画面 + 有路线图 | 红点匀速移动 |
| **D** | 无路线图 | 通用风格：zoom + 画中画 + 字幕 |

## 修改风格（进阶）

### 改特效参数

编辑 `style_labels.json`，修改数值即可：

```json
// 例如：改 zoom 幅度
"scale_start": 1.0,   // 起始缩放
"scale_end": 1.15,    // 结束缩放（改这里变大→更明显的推进效果）

// 例如：改路线图位置
"position": "右上角"   // 改成 "左上角" / "右下角"

// 例如：改画中画大小
"scale": 0.35          // 0.25=较小, 0.5=较大
```

### 学习新风格

换一条新的参考视频，重跑"学风格"流程：

```powershell
# 1. 放参考视频到 ref/
# 2. 运行分析
python scripts/run_asr.py
python scripts/describe_frames.py
python scripts/merge_content_map.py
python scripts/translate_style.py
# 3. 审核生成的 style_labels.json
```

### 添加新的视频类型

如果你的新视频包含当前标签没覆盖的活动（如"倒车入库"、"侧方停车"）：

1. 运行 `describe_frames.py` 时 VLM 会自动输出新的 `activity` 标签
2. 在 `style_labels.json` 的 `RULE_PIP.trigger.any_of` 里加上新标签即可

```json
"any_of": ["activity:起步操作", "activity:停车操作", "activity:倒车入库"]
```

## 常见问题

**Q: 为什么我的视频没有字幕？**  
A: 检查视频是否有人声讲解。纯环境音/驾驶画面不会生成字幕。

**Q: 红点位置不准怎么办？**  
A: 在视频里加上文字标签（如"前方路口右转"），AI 读取文字后会匹配得更准。

**Q: 路线图叠加太亮/太暗？**  
A: 改 `style_labels.json` 里 `overlay_route_map` 的 `opacity` 值（0.5=半透明, 1.0=完全不透明）。

**Q: 想用不同的路线图怎么办？**  
A: 每次处理新视频前，把对应的路线图放到 `input/route_map.png` 即可。路线图不固定，每条路线一张。

**Q: 处理报错了？**  
A: 检查 `input/video.mp4` 是否存在、ffmpeg 路径是否正确（`D:\tools\ffmpeg\...`）。
